## HR Manager / HR Assistant — workload redistribution

You asked whether the Assistant can take some of this burden off the HR Manager. Applying the same principle used for the GM dashboard (a person's home screen should show what needs *their* decision, not every operational detail) — and matching the HR Manager/Assistant split already decided (Assistant handles day-to-day entry and case prep, Manager handles sign-off/escalation only):

- **Disciplinary actions (H1):** HR Assistant prepares the case and drafts the letter from template (already the agreed split). HR Manager's dashboard then only needs a **review-and-finalize queue** — case summary + letter draft already sitting there, one decision to make. Right now the Manager's screen looks like it's doing prep work (plain "Finalize" with nothing behind it) instead of receiving prep work already done.
- **Guard Lifecycle (H2) — RESOLVED:** both HR Manager and HR Assistant can sign off stage moves — this isn't Manager-exclusive. The auto-populated "ready to advance" queue proposed in H2 should appear on both roles' dashboards, so whichever of them is handling it in the moment can act without searching.
- **Disciplinary actions (H1, H6) — stays Manager-only, no change:** Assistant prepares/documents the case (including surfacing the full charge sheet per H6); HR Manager remains the sole finalizing authority.
- **ID Issuance — CONFIRMED strictly Records Officer:** despite appearing bundled into the HR Manager's "Guard Lifecycle & ID Issuance" panel on the current dashboard, ID card issuance is not a HR Manager or Assistant function at all. That panel's ID-issuance piece should be removed from this screen entirely and live only on the Records Officer's page.
- **Personnel Directory (H5, general):** this one seems appropriately shared/reference-level for both roles as-is — no redistribution needed, just the data-hygiene fix.
